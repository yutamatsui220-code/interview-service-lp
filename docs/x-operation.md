## 1. 前提：このアカウントは何のためにあるか

### 売っているもの

| 項目 | 内容 |
|---|---|
| サービス | 経営者・事業責任者に代わって、現場の一次情報を取りに行くインタビュー代行 |
| ポジション | 第 2 象限（重要 × 非緊急）BPO。コンサルでも PR 会社でも調査会社でもない |
| 価格 | 月 10 万円〜（スポット 1.5〜3 万円 / 外部事業企画室 月 80 万円〜） |
| 提供者 | 松井 裕太（個人の顔が出るサービス） |
| コンバージョン | **30 分の無料相談** |

### 誰に届けるか

1. **本命**：BtoB 企業の経営者 / 事業責任者。会議に週 20〜30 時間を取られ、現場に出る時間が構造的に消えている層。
2. **準本命**：事業企画・マーケ・セールスの責任者。失注理由が分からない、事例が作れない、ナレッジが属人化している。
3. **拡散役**：一次情報・顧客理解・Win-Loss 分析・JTBD に関心のあるビジネス職。直接の顧客ではないが、本命層に届けてくれる。

### X 上で取りにいくポジション

> **「一次情報」というテーマの第一人者。**

「インタビュー代行の松井さん」ではなく、**「一次情報の話をしている人＝松井さん」** と認識される状態を作る。サービス名を覚えてもらう必要はない。テーマとの結びつきを作る。

この一貫性が、そのまま LP の主張（「答えはいつも、現場にある。」）と地続きになる。

## 2. KPI 設計

### 北極星指標

- **無料相談の申込数 / 月**

### 先行指標（週次で見る）

| 指標 | 意味 | 見方 |
|---|---|---|
| プロフィールへのアクセス数 | 「この人は誰？」と思われた回数 | **最重要。** ポストの中身が刺さったかの代理指標 |
| リンククリック数 | LP に流れた数 | 固定ポスト / プロフィールリンク経由 |
| 返信・引用の数 | 会話が起きたか | 数より「誰が」反応したか |
| DM 数 | 商談の芽 | 1 件でも来たらその週は成功 |
| フォロワー増加数（質） | 積み上がり | 本命層が何人増えたかを目視で確認 |

### 追わない指標

- **インプレッション数**。バズは本命層のリーチとほぼ相関しない。年商数億〜数十億の BtoB 経営者は 1 万人にリーチするより、100 人の正しい相手に届く方が価値が高い。
- **フォロワー総数**。相互フォローで増やす意味はゼロ。

## 3. コンテンツの 4 本柱と配分

| 柱 | 内容 | 配分 | 狙い |
|---|---|---|---|
| **A. 現場の気づき** | インタビュー現場で実際に起きたこと、聞いた言葉、その解釈 | **40%** | 唯一無二。誰にも真似できない一次情報そのもの |
| **B. 構造・フレーム** | 第 2 象限 BPO、12 フェーズ、90 メニュー、星取り表 | **25%** | 「この人は整理ができる」という信頼の獲得 |
| **C. データ・ファクト** | 出典付きの市場データ | **15%** | 主張の裏付け。引用されやすい |
| **D. スタンス・人となり** | なぜこの仕事をしているか、何を信じているか | **20%** | 相談したいと思わせる。個人商材の生命線 |

### 配分の意図

**A を最優先にする。** B・C・D は他の誰かでも書けるが、A は実際にインタビューをしている人間にしか書けない。ここが薄いと「よくあるビジネス系アカウント」に埋没する。

**A を書く際の絶対条件（§9 も参照）**
- 企業名・業界・規模・時期を、**特定できない粒度まで必ず削る**
- 発言そのままではなく、**構造として抽象化してから書く**
- 迷ったら書かない。守秘への信頼が、この商売の土台

## 4. 投稿の型（7 種）

### 型 1：現場の一言 ―― 引用起点

一次情報アカウントの主力型。**A 柱の標準フォーマット。**

```
インタビューでよく出てくる言葉がある。

「特に問題ないです」

これが出たら、だいたい問題はある。
問題がないのではなく、
問題を言語化する言葉を、まだ持っていないだけ。

だから聞き方を変える。
「直近で一番面倒だった作業は何ですか」
```

構造：**現場の言葉 → 一般認識の否定 → 本当の意味 → 実践的な打ち手**

### 型 2：逆説の指摘

一行目で常識をひっくり返す。プロフィールクリックを取りやすい。

```
一次情報が大事、は全員が知っている。
実際に顧客ニーズを把握できている企業は、5 社に 1 社。

知らないから、やれていないのではない。
重要だが緊急ではないから、後回しになっているだけ。

意志の問題ではなく、構造の問題。
```

### 型 3：構造分解（番号リスト）

保存・引用されやすい。**B 柱の標準フォーマット。**

```
経営者が現場に出られなくなる理由は、能力ではなく構造にある。

① 会議が週 20〜30 時間を占める
② 商談・採用・経営判断・対外発信が重なる
③ 現場訪問は KPI に紐づかない
④ 紐づかないから、最初に予定表から消える
⑤ 結果、メンバーの報告を信じるしかなくなる

レイヤーが上がるほど、一次情報から遠ざかる。
```

### 型 4：データ提示

必ず**出典を明記**する。出典のない数字は書かない。

```
事業企画・管理職の転職求人倍率は 3.82 倍。
全職種平均は 2.74 倍。（doda 求人倍率レポート / 2024 年 9 月）

事業企画は、採用できない職種になりつつある。

だから「採用する」以外の選択肢が要る。
```

### 型 5：チェックリスト / 自己診断

自分ごと化させる。保存が伸びる。

```
社内のヒアリングが機能していないサイン。

□ 報告が「特に問題ありません」で終わる
□ 事実と主観が混ざっていて判別できない
□ 失注理由が「価格」に集中している
□ トップ営業の勝ち筋が、どこにも残っていない

3 つ以上当てはまるなら、
聞く人の能力ではなく、聞く仕組みの問題。
```

### 型 6：ケース（Before → After）

抽象化必須。数字は「想定」「試算」と明示する。

```
失注理由をヒアリングし直すと、順位が入れ替わることがある。

社内の認識：1 位「価格が高い」
聞き直した結果：1 位「導入後の運用イメージが持てない」

前者なら、値下げの議論になる。
後者なら、オンボーディング資料を作る話になる。

打ち手が、まるごと変わる。
```

### 型 7：問いかけ（会話の起点）

**週 1 本まで。** 多用すると中身のないアカウントになる。

```
経営者や責任者の方に聞いてみたいです。

最後にご自身で、顧客に直接ヒアリングをしたのは、いつですか。
```

## 5. 書き方ルール

### 冒頭 1 行がすべて

- タイムラインで見えるのは**最初の 1〜2 行だけ**。ここで刺さらなければ残りは読まれない。
- **NG**：「今日はインタビューについて書きます」「〜について考えてみました」
- **OK**：現場の言葉、意外な数字、常識の否定から始める

### 体裁

- **1 投稿 1 メッセージ。** 詰め込むと何も残らない
- 2〜3 行ごとに空行。スマホで読める塊にする
- 全体で **250〜400 字** を目安（読み切れる長さ）
- 絵文字は使わない。この商材のトーンに合わない
- **ハッシュタグは使わない。** BtoB 経営層には効かず、宣伝色だけが出る

### 数字と出典

- LP と同じ数字を使う（90%+ / 約 20% / 3.82 倍 / 49.6% / 90.2% / 85%）
- **出典を必ず併記する。**「経済産業省 中小企業庁調査」「doda 求人倍率レポート」など
- LP に載っていない数字は使わない。裏取りできないものは書かない

### リンクの扱い

- **本文にリンクを貼らない。** 表示が伸びにくくなるうえ、宣伝ポストに見える
- 導線は **① プロフィール ② 固定ポスト ③ 反応があった時のリプライ** の 3 つ
- 直接の営業ポストは **月 2 本まで**。それ以上は情報提供に徹する

### トーン

LP の文体をそのまま持ち込む。

- 断定するが、押し付けない
- 「教える」立場に立たない（コンサルではない、というポジションと矛盾する）
- 「私たちは〜」より「一人称・現場目線」で書く
- 他社・他サービスを批判しない。**AI 議事録ツールは競合ではなく補完**、というスタンスを崩さない

## 7. ネタ帳（LP 資産の投稿化）

LP の中身をそのまま投稿単位に分解したストック。**34 本以上**。

### 7-1. 12 フェーズ（各 1 本 → 12 本）

各フェーズについて「誰に聞くか / 何が取れるか / それで何が変わるか」の 3 点で書く。

| # | フェーズ | 対象 | ポストの核 |
|---|---|---|---|
| 1 | 戦略策定 | 経営層 / 事業責任者 | 経営仮説は、社内では検証できない |
| 2 | 顧客理解 | 既存・失注・潜在顧客 | KBF は、想像では絶対に当たらない |
| 3 | プロダクト開発 | 利用・非利用・競合ユーザー | 「使っていない人」に聞く価値 |
| 4 | マーケティング | 成功事例顧客 / リード / 離脱 | 響く言葉は、顧客の口の中にしかない |
| 5 | 営業 | 成約 / 失注 / 検討中 | 失注理由の 85% は不正確（Clozd / Arkaro / Unkover） |
| 6 | カスタマーサクセス | 継続・チャーン・拡大顧客 | 継続理由を聞いていない会社が多すぎる |
| 7 | 採用 | 内定者 / 辞退者 / 入社後 | 辞退者にこそ聞くべき |
| 8 | 組織開発 | トップパフォーマー / リーダー | 暗黙知は本人には言語化できない |
| 9 | 退職・離職対応 | 退職者 / 異動者 | 退職面談で本音が出ない構造 |
| 10 | 経営報告・ガバナンス | 経営層 / 株主・投資家 | 戦略仮説の外部検証 |
| 11 | パートナー・アライアンス | 提携先 / 候補先 | 期待値のズレは初期に見える |
| 12 | M&A・Exit | 買い手候補 / 主要顧客 | 事業価値の言語化 |

### 7-2. 9 カテゴリの出口（各 1 本 → 9 本）

A. マーケティング / B. 営業 / C. プロダクト / D. CS / E. 経営戦略 / F. 採用・組織 / G. ナレッジ / H. PR・広報 / I. ファイナンス

**共通の型**：「1 本のインタビューが、◯◯ではこう使える」

### 7-3. FAQ 由来（5 本）

1. AI 議事録ツールとの違い（AI にできない領域は何か）
2. 大手 BPO との違い（最低発注単価という壁）
3. コンサルとの違い（What を教える vs 実行を肩代わりする）
4. インタビュー対象をどう選ぶか
5. 効果はいつ出るか（短期 3 ヶ月 / 中期 半年 / 長期 1 年）

1. 年収 800 万の事業企画 1 名＝初年度 約 1,250 万円（社保 約 120 万＋エージェント費 約 320 万）

### 7-6. 単発の切り口

- 「重要 × 非緊急」が後回しになる構造（第 2 象限）

- 第三者だから聞ける質問がある（中立性の価値）
- 生データで納品する理由（顧客側の AI 環境で内製活用できる）

## 8. プロフィールと固定ポスト

### プロフィールに入れる要素

1. **何をしている人か**：一次情報を取りに行く人／インタビュー代行
2. **誰のためか**：経営者・事業責任者の代わりに
3. **信条**：答えはいつも、現場にある
4. **導線**：LP の URL

### 固定ポスト

以下を 1 本にまとめて固定する（宣伝色は最小限に）。

- なぜ一次情報なのか（90%+ が重要と認識、実際にできているのは約 20%）
- 何を代行するのか（インタビューという「入り口」）
- どこから始められるのか（月 10 万円 / スポット 1.5 万円〜）
- 相談の入口（30 分の無料相談）

**四半期に 1 回、反応の良かったポストに差し替える。**

## 9. やらないこと

| やらないこと | 理由 |
|---|---|
| クライアントが特定できる書き方 | 守秘が崩れた瞬間に、この商売は成立しない |
| 出典のない数字 | 一次情報を掲げるアカウントとしての自己矛盾 |
| 他社・他サービスの批判 | AI 議事録も大手 BPO も、LP 上では「補完」「違うだけ」と定義している |
| 煽り・釣りタイトル | 本命層（経営層）の信頼を最速で失う |
| 政治・宗教・時事の論評 | リスクに対してリターンがない |
| 相互フォロー / フォロー返し目的の運用 | フォロワーの質が落ち、KPI が壊れる |
| 毎日の営業ポスト | 月 2 本まで（§5） |
| バズ狙いの一般論 | リーチは出ても、相談には 1 件もつながらない |

### 反映のルール

1. **分析結果を貼るだけで終わらせない。** 必ず §3〜§6 のどこかを書き換える。書き換える場所がないなら、その分析は運用に影響しないということ。
2. **一度に変える要素は 2 つまで。** 同時に多くを変えると、何が効いたか分からなくなる。
3. **変更後は最低 4 週間、同じルールで回す。** 1 週間の数字で判断しない。
4. **数字が悪化したら元に戻す。** ログがあれば戻せる。
