## 検討の流れ

### 出発点
旅行明けで体調・生活習慣が回復。BUDDICA入社前の今のうちに再開したい。
バチェラーデートの経験から「やり取りありきで会う方が自分に合う」と自己分析済み。
→ **東カレデートでいいのでは？** という仮説からスタート。

### 論点1：東カレ vs with
「実現したい生活や未来を理解してくれる人」で迷いが発生。

ここで判明した論点 → **「理解してくれる」には2種類ある**

| | 意味 | 適する場 |
|---|---|---|
| A | 同じ水準・価値観を最初から持っている（説明不要） | 東カレ |
| B | 目指す方向を受け止めて伴走してくれる（説明したら乗る） | with |

**東カレは「現在値」で戦う場所**（今の年収・職業・見た目）。
**withは「内面と伸びしろ」で戦う場所**（診断ベース・価値観重視）。

→ 決着方法：**東カレの審査を先に出す**。無料で、通るか落ちるかは自分では決められない。
　結果待ちの間にサブのプロフィールを作れば、どちらに転んでもすぐ動ける＝迷う時間がゼロになる。

### 論点2：条件の具体化で with が落ちる
提示された条件：30歳前後 / 顔が可愛い / 自立している / 趣味と友達がある / 時間の融通が効く（自営・ホワイト企業）/ 家庭を持ちたい。

→ **withは20代中心で年齢層がズレる**ため脱落。
→ 条件が全部「検索フィルタで絞れる項目」だったため、母数で殴れる**ペアーズ**が浮上。

### 【転換点1】「たまに会えればOK」の読み違い ⚠️

このとき「お出かけや食事はたまにで問題ない」を
**「関係の優先度が低い」**と解釈し、東カレの文化（エスコート前提・まめに会う空気）と
衝突するリスクを最大の懸念として提示していた。

→ **実際は逆だった。**
- 一緒に住みたい
- 毎週会いたい
- 友達の時間を削ってでもパートナーを優先したい

つまり**優先度は最高**。少ないのは「お出かけ・外食デートというイベント形式」だけで、
**生活を共にすることで一緒の時間を確保するモデル**だった。

→ 東カレへの懸念は消滅。評価を元に戻した。

ここで同時に、目指す生き方も明確化：
**中野さんの生活に憧れている。ビジネスアスリートになりたい。40歳までフルスロットル。**

→ 導出された重要な視点：**必要なのは「理解者」ではなく「共犯者」**
- 理解者 = 仕事を我慢して受け入れる人 → いつか「私と仕事どっちが大事なの」が発生
- 共犯者 = その人生設計を自分のものとして引き受ける人 → そもそもその質問が出ない

→ 口説き方が「支えてほしい」から「**一緒にこういう人生を作りたい**」に変わった。

### 論点3：「自立」の定義
→ **経済的自立ではなく精神的自立**であることが判明。

これにより相手の職業条件が大きく緩む。本質は収入ではなく**時間の主導権**。
時短・パート・リモート・フリーランスまで射程に入る。

また「出張先からもビデオ通話したい」が加わったことで関係の温度が確定。
**物理的に離れても関係は常時接続していたい**タイプ。

→ 導出された見極めポイント：外から見た行動は同じ「毎日ビデオ通話」でも中身が真逆
- ❌ 毎日連絡が**必要**（不安由来）— 途切れると壊れる
- ⭕ 毎日話**したい**（愛着由来）— 途切れても平気だが話せると嬉しい

「精神的自立」と「密な接続」は矛盾しない。動機が違うだけ。

### 【転換点2】「家事は求めない」で人物像が確定 ⚠️

「家庭に軸足を置いてほしい」と「家事は家事代行でいい」は、
並べると相手に矛盾して聞こえる（＝何を求められてるのか分からない）。

→ 言語化した答え：**求めているのは労働ではなく重心**
- ❌ 家事をやる人（役割分担の話）
- ⭕ 人生の重心が家庭側にある人（優先順位の話）

→ さらに判明：**これは弱点ではなく最強の訴求だった。**
30歳前後で家庭に軸足を置きたい人が最も恐れているのは**家政婦化**。
「家事は外注でいい、求めてるのは相棒」は、他の男性がまず書いていない上に、
金銭的余裕とパートナーへのリスペクトを同時に証明できる。

同時に「旅行が大好き、休みが取れたら出かけたい」が追加され、
関係の形が最終確定：**日常は同居で共有、まとまった休みは旅行。**

### 着地：競合環境と勝ち筋
狙う層（30歳前後・時間の主導権あり・経済的に余裕・家庭に軸足）は婚活市場の**人気層**。
ハイスペ男性が同じ層を全力で取りに来るため、**条件のスペック勝負では消耗する**。

→ 勝ち筋は**ビジョンと熱量**。中野さんに憧れてビジネスアスリートを目指す物語を隠さないこと。

→ 最終的なコアメッセージ（本人の言葉）：

> **とにかく面白そう！**
> **特等席で、俺が成長するところを見てよ。**

条件勝負を降りて物語で殴る、という戦略がこの一行に凝縮された。

## この検討から得られた教訓

1. **「たまに会えればOK」は優先度の低さを意味しない。**
   イベントとしてのデート頻度と、関係の優先度は別の軸。ここを混同すると人物像を丸ごと読み違える。

2. **「自立」は経済と精神で分けて考える必要がある。**
   分けないと、相手の職業条件を不要に狭めてしまう。

3. **「家庭に軸足」は労働ではなく重心の話。**
   言語化せずに使うと家政婦要求に聞こえる。言語化すれば最強の訴求になる。

4. **矛盾して見える条件ほど、言語化すると差別化になる。**
   「忙しいけど毎日話したい」「家庭に軸足だけど家事は不要」——
   どちらも整理前は弱点、整理後は他にない強みだった。
