# X 投稿ドラフト（4 週間分 / 24 本）

作成日：2026-08-27
準拠：[`x-operation.md`](./x-operation.md)（§4 投稿の型 / §5 書き方ルール / §6 週次リズム）

---

## 使い方

- 上から順に投下すれば **4 週間分の運用が回る**構成。
- 各ドラフトには **柱（A〜D）／型（1〜7）** を明記。効果測定時にこのラベルで集計する。
- **`【要差し替え】` は、実体験・実データに置き換えてから投稿すること。** 汎用の書き方で出すと、このアカウント最大の武器（実際に現場に行っている人にしか書けないこと）が消える。
- 数字は LP に載っている出典付きのものだけを使用。**出典は削らない。**

# Week 1 ── 「一次情報が取れていない」という現実を突きつける

## W1-月 ｜ C. データ ／ 型 4

```
一次情報が大事だと答える経営者は、9 割を超える。
実際に顧客ニーズを把握できている企業は、5 社に 1 社。

（経済産業省 中小企業庁調査 / イノベーション活動企業 n=558）

この差は、意識の差ではない。
重要だが、緊急ではない。
だから予定表から最初に消える。それだけ。
```

## W1-火 ｜ A. 現場 ／ 型 1

```
ヒアリングで一番よく出てくる言葉。

「特に問題ないです」

これが出たとき、問題がないことはまずない。
問題を言語化する言葉を、まだ持っていないだけ。

だから聞き方を変える。

「直近 1 ヶ月で、一番面倒だった作業は何ですか」

具体的な出来事を聞くと、抽象的な不満が事実に変わる。
```

## W1-水 ｜ B. 構造 ／ 型 3

```
経営者が現場に出られなくなるのは、意識の問題ではない。構造の問題。

① 会議が週 20〜30 時間を占める
② 商談・採用・経営判断・対外発信が重なる
③ 現場訪問は、どの KPI にも紐づかない
④ 紐づかないから、最初に予定から消える
⑤ 結果、メンバーの報告を信じるしかなくなる

レイヤーが上がるほど、一次情報から遠ざかっていく。
```

## W1-木 ｜ A. 現場 ／ 型 6

```
失注理由を聞き直すと、順位が入れ替わることがある。

社内の認識 → 1 位「価格が高い」
本人に聞くと → 1 位「導入後の運用イメージが持てなかった」

前者だと、値下げの議論になる。
後者だと、導入後の資料を作る話になる。

打ち手が、まるごと変わる。

CRM に入力された失注理由の 85% は不正確だという調査もある。
（Clozd / Arkaro / Unkover）
```

## W1-金 ｜ B. 構造 ／ 型 5

```
社内のヒアリングが機能していないサイン。

□ 報告が「特に問題ありません」で終わる
□ 事実と主観が混ざっていて、判別できない
□ 失注理由が、なぜか「価格」に集中している
□ トップ営業の勝ち筋が、どこにも残っていない
□ 顧客に最後に直接会ったのが、いつか思い出せない

3 つ以上あてはまるなら、
聞く人の能力ではなく、聞く仕組みの問題です。
```

## W1-土 ｜ D. スタンス ／ 自由

```
コンサルタントですか、と聞かれることがある。
違います、と答えている。

コンサルは「何をすべきか」を教える仕事。
自分がやっているのは、現場に答えを取りに行く仕事。

教える側に立った瞬間、
現場の話が入ってこなくなる感覚がある。

答えはいつも、現場にある。
```

# Week 2 ── 「聞き方」の技術を見せる（専門性の提示）

## W2-月 ｜ C. データ ／ 型 4

```
事業企画・管理職の転職求人倍率は 3.82 倍。
全職種の平均は 2.74 倍。
（doda 求人倍率レポート / 2024 年 9 月）

事業企画は「採用できない職種」になりつつある。

採れないなら、
外から機能だけ借りるという選択肢が現実的になる。
```

## W2-火 ｜ A. 現場 ／ 型 1

```
インタビューで、絶対に最初に聞かないことがある。

「御社の課題は何ですか」

これを最初に聞くと、
用意された答えが返ってくる。

先に聞くのは、事実。

「その業務、誰が、いつ、どうやってますか」

事実を積んだあとに解釈を聞くと、
本人も気づいていなかった課題が出てくる。
```

## W2-水 ｜ B. 構造 ／ 型 3

```
社内の人間には聞けない質問がある。

・その判断、本当に納得してますか
・上長にはどう報告してますか
・正直、この機能使ってますか

利害関係のある相手には、答えづらい。
評価に響くから。

第三者に価値があるのは、
スキルの差ではなく、立場の差。

中立であること自体が、情報の質を決めている。
```

## W2-木 ｜ A. 現場 ／ 型 6

```
トップ営業に「なぜ売れるんですか」と聞くと、
だいたい「気合ですかね」と返ってくる。

本人が隠しているわけではない。
無意識にやっていることは、本人には見えない。

だから聞き方を変える。

「直近で決まった 1 件、初回接触から受注まで、順番に教えてください」

出来事を順に辿ると、
本人が意識していない共通の型が浮かび上がる。

暗黙知は、第三者の質問で初めて言語化される。
```

## W2-金 ｜ B. 構造 ／ 型 5

```
インタビューの質を決めるのは、質問の数ではなく、順番。

① 事実（誰が、いつ、何を）
② 経緯（どういう流れでそうなったか）
③ 感情（そのとき、どう感じたか）
④ 解釈（それはなぜだと思うか）
⑤ 理想（どうなっていたら良かったか）

いきなり ④ から聞くと、一般論しか返ってこない。
① から積むと、本音が出る。
```

## W2-土 ｜ D. スタンス ／ 自由

```
【要差し替え：直近のインタビューで、自分の予想が外れた経験を 1 つ書く】

想定していた仮説と、実際に聞いた話が違った、という具体例。
「聞かないと分からない」を、自分の失敗として書くと説得力が出る。

締めは、仮説を持つことと、仮説に固執することは違う、という趣旨で。
```

# Week 3 ── 「取ったあと、どう使うか」を見せる

## W3-月 ｜ C. データ ／ 型 4

```
増収増益企業の 49.6% が、生成 AI を業務で使っている。
（Speeda 営業企画白書 2024）

企画立案も、計画づくりも、コンテンツ生成も、
情報さえあれば AI でできる時代になった。

だからボトルネックが移動した。

いま足りないのは、処理する力ではなく、
処理する材料としての一次情報のほう。
```

## W3-火 ｜ A. 現場 ／ 型 1

```
インタビューで一番価値があるのは、
本人が言い淀んだ瞬間だったりする。

「うーん、まあ、はい」

ここで次の質問に進まない。
黙って待つ。

すると 5 秒後くらいに、
それまでと明らかに温度の違う言葉が出てくる。

沈黙は、埋めるものではなく、置くもの。
```

## W3-水 ｜ B. 構造 ／ 型 3

```
1 本のインタビューは、1 つの用途で終わらない。

同じ顧客の話が、

・マーケの事例記事になり
・営業のプレイブックになり
・プロダクトの改善ヒントになり
・採用のペルソナ材料になり
・社内ナレッジの原本になる

入口は 1 つ。出口は複数。

だから「聞きに行く」という行為は、
費用対効果がいちばん高い投資になり得る。
```

## W3-木 ｜ A. 現場 ／ 型 6

```
継続してくれている顧客に、
「なぜ使い続けているんですか」と聞いている会社は少ない。

解約理由は分析するのに、継続理由は分析しない。

でも継続理由こそ、
そのまま営業トークになり、
そのまま LP のコピーになり、
そのまま次の顧客への提案になる。

うまくいっている理由を、言語化しておく。
```

## W3-金 ｜ B. 構造 ／ 型 5

```
事業の中で、インタビューができる場面は 12 ある。

① 戦略策定 ② 顧客理解 ③ プロダクト開発
④ マーケティング ⑤ 営業 ⑥ カスタマーサクセス
⑦ 採用 ⑧ 組織開発 ⑨ 退職対応
⑩ 経営報告 ⑪ アライアンス ⑫ M&A

多くの会社が使っているのは、②と⑤くらい。

残りの 10 は、
聞けるのに聞いていない情報が眠っている場所。
```

## W3-土 ｜ D. スタンス ／ 自由

```
AI 議事録ツールと競合しますか、と聞かれる。
むしろ補完だと思っている。

議事録の作成も、要約も、整理も、AI で十分。
というより、AI のほうが速くて正確。

残るのは、その手前。

何を聞くかを設計すること。
本音が出る空気をつくること。
言い淀みに気づいて、待つこと。

自動化されたぶん、
設計と対話の価値が上がった。
```

# Week 4 ── 「外に出す」という選択肢を提示する

## W4-月 ｜ C. データ ／ 型 4

```
経営課題ランキングの 1 位は「人材強化」。
経営者の 90.2% が最重要課題に挙げている。
（中小企業庁 経営者調査）

一方で、事業企画職の求人倍率は 3.82 倍。（doda / 2024 年 9 月）

一番強化したい機能が、
一番採用しづらい、という状態になっている。
```

## W4-火 ｜ A. 現場 ／ 型 1

```
退職面談で本音が出ないのは、当たり前だと思っている。

辞める側にメリットがないから。

・業界内で悪評が立つかもしれない
・円満に辞めたい
・言っても、もう変わらない

だから「不満はなかったです」で終わる。

本当の理由が聞けるのは、
利害が切れた第三者に対してだけ、ということが多い。
```

## W4-水 ｜ B. 構造 ／ 型 3

```
BPO の対象が、この数年で移動している。

これまで：重要度は低いが、緊急度が高い定型業務
（経理処理、データ入力、コールセンター）
→ 目的はコスト削減

いま：重要度は高いが、緊急度が上がらない業務
（顧客インタビュー、事例制作、営業の型化）
→ 目的は事業推進

前者は AI で自動化が進んだ。
後者は、社内では永遠に着手されない。

外に出す理由が、変わってきている。
```

## W4-木 ｜ B. 構造 ／ 型 6

```
事業企画を 1 名採用するときの、初年度の総コスト。

年収 800 万円
＋ 社会保険料 約 120 万円
＋ 採用エージェント費 約 320 万円
= 約 1,250 万円

さらに、
採用までに 3〜6 ヶ月。
ミスマッチの可能性は約 30%。
合わなくても、契約は切れない。

「正社員を採るほどではないが、
　事業企画の知見は欲しい」

この状態に、まだ名前がついていない気がする。
```

## W4-金 ｜ B. 構造 ／ 型 5

```
一次情報を取りに行く前に、決めておくこと。

□ 誰に聞くか（成約 / 失注 / 継続 / 解約 / 退職者）
□ 何を判断するために聞くか
□ 聞いた後、誰がそれを使うか
□ どの形式で残すか（生データか、要約か）
□ いつまでに、何本聞くか

このうち「聞いた後、誰が使うか」が空欄のまま
始まる案件が、いちばん多い。

出口を決めてから、入口を設計する。
```

## W4-土 ｜ D. スタンス ／ 型 7（会話の起点）

```
経営者・事業責任者の方に聞いてみたいです。

最後にご自身で、顧客に直接ヒアリングをしたのは、いつでしたか。

半年以上前だとしたら、
それは怠慢ではなく、
たぶん構造のほうに理由があります。
```
